## `01` / About Me

I'm a frontend developer focused on building modern, responsive websites and thoughtful digital experiences.

I enjoy turning ideas and designs into functional products, refining user interfaces, and making websites feel as good as they perform.

- **Building:** Responsive websites, polished interfaces, and client projects.
- **Working with:** React, Next.js, JavaScript, TypeScript, and Tailwind CSS.
- **Interested in:** Frontend architecture, web performance, and design engineering.
